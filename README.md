# Button Styling Update

All buttons in this repository now use a red color scheme.

## Button Styles Applied

- **Primary Color**: Red (#FF0000)
- **Hover State**: Dark Red (#CC0000)
- **Active State**: Darker Red (#990000)
- **Disabled State**: Light Red (#FFCCCC)

## Usage

Include the `styles/buttons.css` file in your HTML:

```html
<link rel="stylesheet" href="styles/buttons.css">
```

All standard buttons, button classes, and submit inputs will automatically use the red color scheme.

## Supported Selectors

- `<button>` elements
- `.button` class
- `.btn` class
- `<input type="button">`
- `<input type="submit">`
- `<input type="reset">`
